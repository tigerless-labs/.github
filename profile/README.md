## Agent skills & infrastructure

Reusable skills and harnesses that make coding agents sharper over time.

- **[autoharness](https://github.com/tigerless-labs/autoharness)** [![stars](https://img.shields.io/github/stars/tigerless-labs/autoharness?style=social)](https://github.com/tigerless-labs/autoharness/stargazers) — A self-learning skill layer for Claude Code: distills skills from your real sessions, updates them as you work, and prunes the ones that go unused.
- **[design-harness](https://github.com/tigerless-labs/design-harness)** [![stars](https://img.shields.io/github/stars/tigerless-labs/design-harness?style=social)](https://github.com/tigerless-labs/design-harness/stargazers) — Feed your agent papers and half-formed ideas; it links them into a system design you can defend. An Agent Skill for Claude Code and any SKILL.md-compatible agent.

## Observability & safety

See and control what your agents actually send — cost, context, and data boundaries.

- **[cost-xray](https://github.com/tigerless-labs/cost-xray)** [![stars](https://img.shields.io/github/stars/tigerless-labs/cost-xray?style=social)](https://github.com/tigerless-labs/cost-xray/stargazers) — See what Claude Code and Codex actually send to the API — and what each part costs.
- **[phi-context-boundary-report](https://github.com/tigerless-labs/phi-context-boundary-report)** [![stars](https://img.shields.io/github/stars/tigerless-labs/phi-context-boundary-report?style=social)](https://github.com/tigerless-labs/phi-context-boundary-report/stargazers) — PHI boundary reports for healthcare and insurance AI workflows — across prompts, RAG, tools, memory, and logs.
